# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and focus on the work. Harassment and personal attacks are not tolerated.

You can report unacceptable behavior privately to the maintainer through a [GitHub security advisory](https://github.com/wellwind/SessionBay/security/advisories/new) or by contacting [@wellwind](https://github.com/wellwind). Reports are handled confidentially.
