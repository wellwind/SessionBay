# Session Bay 介面與操作規格

介面以管理自選目錄的「專案」為預設首頁，另設「所有目錄」頁保留全部 Session 相關目錄分組。兩頁皆先呈現分組總覽，選取後才查看歷史，同時支援執行工作。Agent 對話預覽、專案清單、工作區布局、正在執行的 Terminal 各自保留狀態。

## 資訊架構

```text
Session Bay
├─ 導覽頁面（兩頁皆有總覽卡片＋側欄）
│  ├─ 專案（預設首頁；僅使用者明確加入）
│  └─ 所有目錄（所有有 Session 的目錄）
├─ 選取目錄／專案後
│  ├─ 歷史 Session
│  │  ├─ Codex
│  │  ├─ Claude Code
│  │  ├─ Grok Build
│  │  └─ Antigravity CLI（已辨識格式；版本驗收另列）
│  └─ 工作區分頁
│     └─ 分割面板
│        ├─ Agent Terminal
│        └─ 普通 Terminal
├─ 已開啟工作區（兩頁皆可到達；包含未加入專案的工作區）
├─ 用量（P1，MVP 後）
│  ├─ Agent 與帳號額度
│  └─ Project／Agent／Session 分析
└─ 設定與資料來源
```

歷史 Session 是資料，面板是視圖，Runtime 是程序；三者有關聯，但不互相等同。

## 主畫面

```text
┌───────────────────────────────────────────────────────────────┐
│ Session Bay             搜尋專案或對話                 設定     │
├──────────────┬────────────────────────────────────────────────┤
│ 專案      ＋ │ my-project  /work/my-project                  │
│ 所有目錄     │ [歷史] [開發工作區]                   ＋新增     │
│ ★ my-project ├──────────────────────┬─────────────────────────┤
│   project-b  │ Codex                │ Terminal                │
│ 已開啟工作區 │ 重構登入流程          │ npm run dev             │
│   temp-work  │                      │                         │
│              │                      │                         │
├──────────────┴──────────────────────┴─────────────────────────┤
│ 索引狀態                         目前焦點與程序狀態             │
└───────────────────────────────────────────────────────────────┘
```

上圖為已選取目錄後的工作檢視。尚未選取時，主區域顯示目前頁面的專案／目錄總覽卡片，不顯示混合多目錄的 Session 清單。

「歷史」是所選目錄的資料檢視，工作區分頁用來執行程序。進入歷史時，中間顯示 Session 清單與可收合的對話預覽；啟動後可回到工作區，保留原先搜尋條件。

## 專案導覽

預設「專案」頁的總覽卡片與側欄只顯示 `curated: true` 的目錄，包括尚無歷史的專案；可搜尋及拖曳自訂專案順序，保留排序把手與 Alt＋上／下快捷鍵，不再顯示上／下移按鈕；首次承接舊置頂／活動順序，後續記住順序並追加新專案。清單與開啟中的工作區可獨立收合並記住狀態；掃描不自動增加項目。

「所有目錄」頁的總覽卡片與側欄列出 `sessionCount > 0` 的全部 catalog 分組，不排除已加入專案的目錄。兩頁都先選擇一組，再顯示該組的 Session 清單、搜尋與預覽；總覽不顯示跨目錄混合 Session。另保留明確的跨目錄搜尋入口，只有主動開啟才顯示全域結果，不改變兩頁的分組首頁。名稱相同時補上父目錄；完整路徑可查看與複製。

未分類、失效路徑及未加入專案的目錄仍列在所有目錄頁，失效路徑與來源錯誤以明確標記呈現。只有實際存在、可加入的目錄才提供有效的「加入專案」操作；缺 cwd 的歷史仍可搜尋，不能猜測目錄。

專案操作的「移出專案」只取消加入與釘選。操作說明明列不會刪除歷史或資料夾、不會停止程序；已開啟工作區在兩頁皆有入口，移出後仍能切回、操作與明確關閉。不以移出觸發關閉程序確認，也不在下一次掃描自動加回。

## 加入或建立專案

專案區的新增入口提供兩個選項，與工作區內的「新增工作」分開：

1. **加入既有目錄**：輸入完整絕對路徑，可填顯示名稱；驗證該目錄存在後加入並選取。重複加入會使用同一專案，不建立副本。
2. **建立新專案**：輸入已存在父目錄的絕對路徑及單一新資料夾名稱；顯示目標位置後建立，再加入專案。既有目標、巢狀名稱、`.`、`..` 或不存在的父目錄均回報錯誤，不覆寫或遞迴補建。

加入目錄、建立專案的上層目錄、重新定位、工作目錄與歷史來源根目錄均可按「選擇資料夾」開啟原生單選對話框，並保留手動輸入（包含隱藏目錄）。選取只回填目前草稿，不自動儲存、掃描或啟動；取消保持原值，失敗顯示欄位提示並可重試。選取中避免重複開啟；欄位編輯、切換模式、儲存鎖定或離開表單後，不套用過時結果。瀏覽器預覽停用選取按鈕並說明可手動輸入。Shell／Agent 執行檔欄位保持文字輸入，不使用資料夾篩選器。取消不建立資料夾或專案；提交失敗保留輸入與錯誤訊息。建立成功僅建立目錄及會員資格，不自動啟動 Agent 或 Shell。

在所有目錄頁先選擇目錄，再查看該組歷史；目錄檢視與對話預覽以完整路徑說明所屬位置。未加入的可用目錄提供「加入專案」，已加入則顯示目前狀態；加入前後保留搜尋與對話脈絡，無需先啟動工作。

## Agent 與歷史來源設定

設定選擇器固定提供 Codex、Claude Code、Grok Build、Antigravity CLI 與 OpenCode，無論是否找到執行檔、已啟動過或已配置來源；只展開目前選中 Agent 的工具與歷史能力卡片。可啟動、有 adapter、來源未設定／停用／缺失與索引健康分開顯示；Antigravity 來源限定 CLI，明示相容性驗證狀態；備份或證據不完整的 Session 仍可預覽，但以原因說明為何不能直接接續。

工具「重新偵測」更新保存設定對應的安裝／版本，歷史「重新掃描」另更新來源健康；兩者不互相取代。

升級保留原有來源。缺少 Grok 來源時提供設定按鈕，加入可編輯的來源草稿，使用者填絕對路徑並保存後才生效；不猜 home、不因開啟設定就自動索引新位置。同一工具可管理多個不同來源，取消不保存草稿。

## 新增工作

新增入口先選兩種工作類型，再呈現對應的設定：

1. **Agent 工作**：從帶有工具標誌的共用登錄下拉清單選 Codex、Claude Code、Grok Build 或 Antigravity CLI，不逐一增加頂層工具按鈕；開始新 Session，或從支援的歷史接續。Grok／Antigravity 另可輸入手動 ID；Antigravity CLI 索引接續須通過原生來源與對話身份檢查。
2. **Terminal**：在專案目錄開預設 Shell，或選擇 Profile 與目錄。

分割面板沿用同一組選項。新面板預設使用專案目錄；若要沿用目前 Shell 已切換的 cwd，須有 Shell integration 等可靠來源，不能僅從 prompt 文字推斷。

### Shell Profiles 與重新偵測

全新設定使用有效絕對 `$SHELL`，否則 macOS 預設 `/bin/zsh`、Linux 預設 `/bin/bash`，參數 `[-l]`。不匯入其他 Terminal Profiles 或 rc 檔，Shell 自行處理啟動設定。重新偵測只列候選執行檔，由使用者明確加入並保存，不自動替換既有 Profiles 或預設項；自訂名稱、參數與 env 保留。

### 啟動參數與風險可見性

設定為五個 Agent 分別提供 executable、JSON argv 陣列及高風險選項勾選。預設關閉；警告說明可能無提示地執行命令或讀寫／刪除檔案，且不同工具對沙箱的影響不同。明確保存後跨重開沿用，啟動器保留風險提示，不再每次彈確認視窗。改變一個工具不影響其他工具；取消勾選後仍有需同意的旗標時，保存顯示可修正錯誤。

新增工作以後端 `preview_launch` 顯示精確 executable、argv 陣列與 cwd。預覽載入中、失敗或參數改變尚未重新驗證時，不能用舊預覽啟動；失敗保留輸入。預覽是檢查而非執行，登入、CLI 內建設定及實際接續結果仍由原工具決定。危險模式不影響搜尋、預覽或加入專案等唯讀／導覽操作。

## 找回工作的操作流程

1. 從預設專案總覽選擇已加入的專案，或切至所有目錄總覽選擇歷史所屬目錄；再搜尋該組 Session。
2. 依標題、Agent、時間與命中片段挑選候選。
3. 預覽最近對話，必要時展開較早訊息。
4. 點選「接續工作」。應用檢查工具、目錄與紀錄。
5. 開啟 Agent 面板；若已有同一受管 Session，聚焦原面板。
6. 需要手動操作時，分割新增普通 Terminal。

搜尋、選取、預覽與加入專案均不觸發 Agent 執行。直接接續尚未加入專案的 Session 不會自動加入側欄；工作區仍能從已開啟工作區入口找回。

## 面板操作

- 支援左右與上下分割、比例拖曳、鍵盤切換焦點。
- 聚焦面板有可辨識標記，不能只靠色彩區分。
- 暫時最大化後可回到原布局。
- 不同專案的工作區分開顯示；面板頂部始終能確認工作目錄與工具。
- 切換分頁保留背景執行；關閉面板依產品規格結束受管程序。
- 普通 Shell 經 broker 確認正常退出（結束碼 `0`）時自動移除面板及可能空出的分頁；其餘面板與程序不受影響。Agent、異常或未知結束碼保留畫面供檢視。
- Agent、非零／未知結束碼及錯誤同樣保留輸出與診斷，提供重新開 Shell 或恢復 Agent 的入口；broker／電腦重啟後清楚標示 interrupted，不冒稱原程序仍在。
- 對仍執行中的程序，關閉確認清楚列出將受影響的面板，不使用模糊的「離開」文案。

## 快速切換與快捷鍵

提供 Command Palette。搜尋 Session 預設使用 `Mod+Shift+F`（macOS 為 Cmd，Linux 為 Ctrl），切至目前所選專案／目錄的歷史並聚焦搜尋框，保留該組範圍；未選組時，明確使用此快捷鍵或跨目錄搜尋按鈕可進入全域搜尋；不因開啟／切換導覽頁面就顯示全域 Session 清單。快捷鍵可在設定調整，需避開 Shell、終端應用與作業系統常用按鍵。

命令至少包含開 Terminal、開始 Agent 工作、搜尋 Session、左右或上下分割、下一面板、暫時最大化與關閉面板。按鈕、選單與快捷鍵共用 command registry。命令面板搜尋欄保持焦點；↑／↓ 循環選取可用命令與專案，Enter 執行，Escape 關閉並返回原焦點。搜尋變更重設至第一個可用項目；停用／無結果不執行，組字期間不觸發。選取高亮並自動捲動，滑鼠指向同步選取。

## MVP 後的用量介面

新增全域「用量」入口，將「帳號額度」與「用量分析」分成兩個檢視。前者以 Agent／供應商／帳號顯示額度窗口、剩餘量、重置與來源更新時間；後者提供日期、Project、Agent、Session 及模型篩選，顯示 token 趨勢與可計價部分。

專案內新增「用量」檢視，以 Project × Agent 彙總下鑽至 Session；歷史詳情提供 Session 用量及來源核對入口。切換時保留搜尋與篩選狀態。共享額度標示「帳號共享」，短期額度不標成對話 Session。

缺資料、不支援、離線、過期及無法定價需有明確狀態；部分小計附涵蓋範圍，未知不用零值代替。圖表之外保留可讀表格及鍵盤操作。估算與實際帳務金額分開呈現，不把月費自動分攤到專案。

來源連線與選用本機 metrics 收集在設定中啟用；用量檢視不執行 Agent 或注入 CLI 命令。詳細行為見[用量規格](usage-spec.md)，整組介面在 P1 交付。

## 客製化與可及性

輸入框外框使用一致的焦點提示；下拉選單、checkbox 與日期欄位共享樣式與清楚標籤，維持鍵盤、焦點及可及性語意，不能只有視覺替身而無可操作控制項。

主題設定共用 design tokens，再分別映射至介面與 xterm 色票。提供字型、大小、對比與快捷鍵設定，支援鍵盤操作、清楚的焦點順序與螢幕閱讀器驗證。

UI 框架採宣告式狀態。Terminal 高頻輸出由 xterm 實例接收，不把每段輸出轉成整個畫面的重新渲染。

## 介面驗收任務

使用者不經說明即可辨認目前專案、工具、焦點與程序狀態；能以鍵盤完成搜尋、預覽、接續與分割。至少兩個 Terminal 在同一畫面持續輸出，調整布局不重啟程序。

導覽變更另驗證：預設專案首頁、兩頁分組總覽與側欄、全新掃描有歷史但專案清單為空、所有目錄含已加入／未加入／未知／失效分組、選組後才查歷史、預覽加入、加入既有目錄、建立新資料夾、重複提交及取消、重開保存、移出後仍可在所有目錄找回歷史且兩頁可操作已開啟工作區。設定另驗證五工具均可選且只顯示選中 Agent、舊設定缺 Grok 的草稿與保存、來源狀態分離及 Antigravity CLI 的相容性／僅預覽提示。使用隔離雲端合成路徑的結果不能代替使用者電腦上的原生目錄操作驗收。

### 最終追加操作契約

- 工作分頁保留快捷鍵：macOS `⌘⇧[`／`⌘⇧]` 為主要上一／下一組合，另有 `⌘⌥←`／`⌘⌥→`；兩平台 `Ctrl+Tab`／`Ctrl+Shift+Tab` 循環。macOS `⌘1–8`、Linux `Ctrl+1–8` 選相應工作分頁，`⌘9`／`Ctrl+9` 選最後。作用範圍為目前目錄的工作分頁，不包含「專案／所有目錄」導覽或「歷史 Session」。組字或模態對話框期間不攔截，處理後不傳送 PTY；說明與保留衝突提示在設定中可見。
- 「偵測歷史來源」位於選中工具的來源卡片，只有已支援 parser 的工具可用。檢查官方 env/home 候選，顯示完整根路徑、可讀／不存在／無權限／檢查失敗；找到目錄不能標成已有對話。使用者按加入後僅更新草稿，儲存與掃描仍需明確操作；已配置的 canonical 同目錄不可重複加入。
- 日期顯示使用有效的瀏覽器語言偏好；Linux POSIX locale（例如 C）無法用作 BCP 47 時安全退回 zh-TW。日期輸入／篩選仍以本地 ISO 日期運作。
- 特定 CapsLock 組字修正只防止 xterm 5.5.0 的提前 flush，不刪除或去重使用者輸入。兩次合法相同中文、一般文字與貼上均須原樣保留；macOS 真實 IME 仍待人工驗收。

## 全域臨時 Terminal

頂列常駐入口與命令面板可直接開預設 Shell，初始 cwd 由 Rust 取得家目錄。未選專案時普通 Terminal 快捷鍵亦使用此入口。全域分頁有獨立 active selection；側欄可從任一目錄頁切回，切換不 unmount／重啟程序。最後一個面板關閉後保留可再次開啟的空狀態，不落入假的 home 專案。完整行為、舊 explicit-cwd Shell 相容及原生待驗清單見[全域臨時 Terminal](temporary-terminal.md)。

### Terminal 原位 Shift＋Enter

所有 Terminal（包含 Shell、未知工具與 Windows）一律將 Shift＋Enter 傳送為 CSI-u modified Enter，輸入留在 Terminal，不開 modal，也不顯示模式選單或額外按鍵說明。一般 Enter、組字、貼上及輸入目標守衛不變。編碼一致不等於所有程式都支援換行；詳細版本、Grok 送出語意及原生驗收限制見 [Terminal 按鍵](terminal-keyboard.md)。

macOS Cmd+W／File → Close Tab 關閉目前工作區分頁（包含分割面板）；有執行中工作先確認。最後一個分頁關閉仍保留視窗。對話框與 IME 組字期間不觸發；Cmd+Shift+W 仍為關閉焦點面板，Cmd+Q 與紅色關閉鈕仍為離開應用程式。

### Agent 個別設定與停用

設定 → 來源與工具先選 Agent，可依名稱搜尋並查看啟用／工具偵測狀態；只展開選中 Agent 的工具、權限參數與多個歷史來源。切換保留整份未儲存草稿，沒有自動偵測或啟動。啟用開關於儲存後生效，取消可還原；停用仍可編輯配置。各資料來源開關獨立保留，Agent 停用時說明暫停掃描。停用保留已索引歷史及現有工作，新的啟動／恢復需要先啟用。所有 Agent 停用仍可開 Shell。

瀏覽器合成回歸入口：`node node_modules/@playwright/test/cli.js test --config playwright.agent-settings.config.ts`，預設使用 Chrome，亦可透過 `CHROMIUM_PATH` 指定 Chromium。覆蓋深／淺色、1200／560px 與選擇／切換啟用操作；不等同原生 WebView 或實際 Agent 驗證。

### Agent 狀態（2026-10-17）

側欄獨立可收合的 Agent 狀態區顯示總計，各專案展開後列出 Runtime；全域工作階段不混入專案。標題列同時提供文字生命週期，不只使用狀態圓點。存活顯示活動未知，斷線顯示存活未知。點選狀態列回到既有面板，不啟動新程序。計數與既有專案歷史 Session 數分開。

### 分頁順序操作

按住分頁名稱並移動至少 5px 可調整同一專案（或全域工作區）內的順序；邊緣指示線顯示插入位置，放開才套用並保存。Escape 或移到分頁區域外放開會取消。一般點擊仍切換分頁，重新命名與關閉按鈕不啟動排序；Alt 加左右方向鍵可用鍵盤調整順序。排序不改變目前作用中的分頁與 Terminal 身分。

## Agent 檔案輸入

已聚焦的直接本機 Agent 終端接受一般檔案 drop 與 paste（含空檔）；完成後提示已插入路徑、尚未送出。有實際檔案時忽略附帶文字表示，拖入未聚焦分割面板時先聚焦該目標；資料夾或不支援路由在當次操作說明，不顯示通用相容性 banner。滿額提示實際保留目錄與安全手動清理前提；管理 UI 尚未提供。詳見 [一般檔案輸入](file-input.md)。

## 工作區專注模式

選取專案或臨時 Terminal 後，可用分頁列「專注」收起頂欄、側欄、大型專案標題與例行狀態列。保留歷史／工作分頁、＋、原有面板操作與常駐「退出專注」。點擊專案名稱可展開完整導覽及設定，再次點擊收起；離開專案到總覽時顯示完整控制。退出後還原原側欄偏好，不重建終端或重設分割布局。

命令面板提供進入／退出命令。快捷鍵可在設定指定，預設無綁定；Escape 繼續由終端與對話框處理。錯誤、連線／程序狀態與必要操作不因專注模式消失。此功能與作業系統全螢幕及單一面板最大化互相獨立。

分頁只有一個 Terminal／Agent 面板時，面板貼齊分頁內容區，不顯示外層卡片留白、邊框與圓角；文字保留閱讀內距。分割後恢復既有間距與可拖曳分隔線，關閉至單面板時再次滿版。其他分頁的隱藏面板不影響判斷，一般與專注模式皆適用。

## Session 資源回收筒

在對話預覽選擇「刪除 Session」，確認對話標題及「僅隱藏 Session Bay 歷史、原始歷史保留、執行中工作繼續」後移入回收筒。取消／Escape 不改資料；送出期間禁止重複操作。成功顯示「復原刪除」。全域頁首可開啟資源回收筒，不必先選取專案；顯示標題、Agent、來源、Session ID 與移入時間，逐筆還原並更新歷史計數。缺少來源的項目仍列出，提示重新連接及掃描，不提供無效的還原按鈕。

### 排序的即時讓位

專案列與工作區分頁拖曳時，來源沿垂直／水平軸跟隨指標，鄰近項目平滑讓出實際落點；不顯示插入線。放開才儲存，Esc 或移出有效區域放開取消。專案列不另外顯示上／下移按鈕；鍵盤聚焦排序把手後用 Alt＋↑／↓，分頁用 Alt＋←／→。系統減少動態效果時取消過渡動畫。

### Session 列表快速刪除

每列右側提供移入資源回收筒按鈕：hover／focus-within 顯示，觸控常駐，預留位置避免跳動。選取與刪除為兩個同層操作；刪除不先開啟該對話預覽。確認後可復原，取消返回原按鈕焦點，成功後焦點移至復原按鈕。

專案頁的重新命名入口為標題旁固定大小的鉛筆圖示按鈕，保留可存取名稱、title 與原有名稱編輯流程；標題可換行，工具列不再重複放大型重新命名按鈕。

專案頁工具列的資源回收筒及移出／加入專案亦採具 title／aria-label 的圖示按鈕，Terminal 與新增工作保留文字按鈕。移出專案以資料夾減號表示，tooltip 明示不刪對話、檔案或關閉程序，避免與垃圾桶混淆。

若刪除完成後仍在等待歷史更新，使用者已操作其他控制項或開啟另一個對話框，晚到的更新不得把焦點拉回復原按鈕。
