# Session Bay 介面與操作規格

介面提供「所有工作階段」與使用者自選的「專案」兩個入口，同時支援找歷史與執行工作。Agent 對話預覽、專案清單、工作區布局、正在執行的 Terminal 各自保留狀態。

## 資訊架構

```text
Session Bay
├─ 所有工作階段（全部可索引歷史與跨目錄搜尋）
├─ 專案（僅使用者明確加入）
│  ├─ 歷史 Session
│  │  ├─ Codex
│  │  ├─ Claude Code
│  │  └─ Grok Build
│  └─ 工作區分頁
│     └─ 分割面板
│        ├─ Agent Terminal
│        └─ 普通 Terminal
├─ 已開啟工作區（包含未加入專案的工作區）
├─ 用量（P1，MVP 後）
│  ├─ Agent 與帳號額度
│  └─ Project／Agent／Session 分析
└─ 設定與資料來源
```

歷史 Session 是資料，面板是視圖，Runtime 是程序；三者有關聯，但不互相等同。

## 主畫面

```text
┌───────────────────────────────────────────────────────────────┐
│ Session Bay             搜尋專案或對話                 設定     │
├──────────────┬────────────────────────────────────────────────┤
│ 所有工作階段 │ my-project  /work/my-project                  │
│ 專案      ＋ │ [歷史] [開發工作區]                   ＋新增     │
│ ★ my-project ├──────────────────────┬─────────────────────────┤
│   project-b  │ Codex                │ Terminal                │
│ 已開啟工作區 │ 重構登入流程          │ npm run dev             │
│   temp-work  │                      │                         │
│              │                      │                         │
├──────────────┴──────────────────────┴─────────────────────────┤
│ 索引狀態                         目前焦點與程序狀態             │
└───────────────────────────────────────────────────────────────┘
```

「歷史」是專案的資料檢視，工作區分頁用來執行程序。進入歷史時，中間顯示 Session 清單與可收合的對話預覽；啟動後可回到工作區，保留原先搜尋條件。

## 專案導覽

「所有工作階段」是固定的完整歷史入口。側欄專案只顯示明確加入的目錄，可在其中搜尋、依活動排序及「置頂」；置頂只是清單內的優先順序，不等於加入或移出。不因掃描發現大量 cwd 而自動增加項目。名稱相同時補上父目錄；完整路徑可查看與複製。沒有歷史的自選專案也可開 Terminal 或 Agent。

未分類及未加入專案的目錄可在所有工作階段中找到，失效路徑與來源錯誤以明確標記呈現。只有實際存在、可加入的目錄才提供有效的「加入專案」操作；缺 cwd 的歷史仍可搜尋，不能猜測目錄。

專案操作的「移出專案」只取消加入與釘選。操作說明明列不會刪除歷史或資料夾、不會停止程序；已開啟工作區另有入口，移出後仍能切回、操作與明確關閉。不以移出觸發關閉程序確認，也不在下一次掃描自動加回。

## 加入或建立專案

專案區的新增入口提供兩個選項，與工作區內的「新增工作」分開：

1. **加入既有目錄**：輸入完整絕對路徑，可填顯示名稱；驗證該目錄存在後加入並選取。重複加入會使用同一專案，不建立副本。
2. **建立新專案**：輸入已存在父目錄的絕對路徑及單一新資料夾名稱；顯示目標位置後建立，再加入專案。既有目標、巢狀名稱、`.`、`..` 或不存在的父目錄均回報錯誤，不覆寫或遞迴補建。

本次以絕對路徑欄位輸入，尚無原生目錄選擇器。取消不建立資料夾或專案；提交失敗保留輸入與錯誤訊息。建立成功僅建立目錄及會員資格，不自動啟動 Agent 或 Shell。

在所有工作階段選取對話後，預覽以完整路徑說明所屬目錄。未加入的可用目錄提供「加入專案」，已加入則顯示目前狀態；加入前後保留搜尋與對話脈絡，無需先啟動工作。

## 新增工作

新增入口提供兩個主要動作：

1. **Agent 工作**：選 Codex、Claude Code、Grok Build 或 Antigravity CLI，開始新 Session，或從支援的歷史接續。Grok／Antigravity 另可輸入手動 ID；Antigravity 明示尚無歷史索引／預覽。
2. **Terminal**：在專案目錄開預設 Shell，或選擇 Profile 與目錄。

分割面板沿用同一組選項。新面板預設使用專案目錄；若要沿用目前 Shell 已切換的 cwd，須有 Shell integration 等可靠來源，不能僅從 prompt 文字推斷。

### 啟動參數與風險可見性

設定為四個 Agent 分別提供 executable、JSON argv 陣列及高風險選項勾選。預設關閉；警告說明可能無提示地執行命令或讀寫／刪除檔案，且不同工具對沙箱的影響不同。明確保存後跨重開沿用，啟動器保留風險提示，不再每次彈確認視窗。改變一個工具不影響其他工具；取消勾選後仍有需同意的旗標時，保存顯示可修正錯誤。

新增工作以後端 `preview_launch` 顯示精確 executable、argv 陣列與 cwd。預覽載入中、失敗或參數改變尚未重新驗證時，不能用舊預覽啟動；失敗保留輸入。預覽是檢查而非執行，登入、CLI 內建設定及實際接續結果仍由原工具決定。危險模式不影響搜尋、預覽或加入專案等唯讀／導覽操作。

## 找回工作的操作流程

1. 選擇自己加入的專案，或進入所有工作階段跨目錄搜尋。
2. 依標題、Agent、時間與命中片段挑選候選。
3. 預覽最近對話，必要時展開較早訊息。
4. 點選「接續工作」。應用檢查工具、目錄與紀錄。
5. 開啟 Agent 面板；若已有同一受管 Session，聚焦原面板。
6. 需要手動操作時，分割新增普通 Terminal。

搜尋、選取、預覽與加入專案均不觸發 Agent 執行。直接接續尚未加入專案的 Session 不會自動加入側欄；工作區仍能從已開啟工作區入口找回。

## 面板操作

- 支援左右與上下分割、比例拖曳、鍵盤切換焦點。
- 聚焦面板有可辨識標記，不能只靠色彩區分。
- 暫時最大化後可回到原布局。
- 不同專案的工作區分開顯示；面板頂部始終能確認工作目錄與工具。
- 切換分頁保留背景執行；關閉面板依產品規格結束受管程序。
- 啟動中／執行中的普通 Shell 正常退出（結束碼 `0`）時自動移除面板；最後一個面板退出則關閉該分頁，不留下空白 Terminal。
- Agent、非零／未知結束碼及錯誤保留輸出與診斷，提供重新開 Shell 或恢復 Agent 的入口；已退出及還原占位不重複觸發自動關閉。
- 對仍執行中的程序，關閉確認清楚列出將受影響的面板，不使用模糊的「離開」文案。

## 快速切換與快捷鍵

提供 Command Palette 與專案或 Session 快速切換器。快捷鍵正式按鍵組合待定，需避開 Shell、終端應用與作業系統常用按鍵。

命令至少包含開 Terminal、開始 Agent 工作、搜尋 Session、左右或上下分割、下一面板、暫時最大化與關閉面板。按鈕、選單與快捷鍵共用 command registry。

## 必備畫面狀態

| 狀態 | 介面行為 |
| --- | --- |
| 首次啟動 | 顯示偵測到的來源，允許修改路徑與選擇開始索引 |
| 沒有 Agent | 可指定執行檔，仍可使用普通 Terminal |
| 沒有歷史 | 提供加入專案與開始新工作 |
| 尚未加入任何專案 | 說明可加入既有目錄或建立新專案；所有工作階段繼續顯示已發現歷史 |
| 專案移出但工作區仍開啟 | 專案清單移除該項，已開啟工作區入口保留，程序不變 |
| 加入／建立路徑無效 | 顯示完整目標與可修正原因，保留輸入，不建立額外目錄 |
| 索引中 | 顯示階段與已處理數量，既有資料仍可操作 |
| 搜尋無結果 | 顯示目前篩選條件，提供放寬範圍與更新索引 |
| 目錄不存在 | 歷史仍可看；恢復前選擇新路徑 |
| 格式不支援 | 保留可用 metadata，說明無法預覽的部分 |
| 恢復失敗 | 顯示 CLI 錯誤與可採取的下一步 |
| Session 狀態未知 | 明確顯示未知，不用修改時間假裝程序存活 |

## MVP 後的用量介面

新增全域「用量」入口，將「帳號額度」與「用量分析」分成兩個檢視。前者以 Agent／供應商／帳號顯示額度窗口、剩餘量、重置與來源更新時間；後者提供日期、Project、Agent、Session 及模型篩選，顯示 token 趨勢與可計價部分。

專案內新增「用量」檢視，以 Project × Agent 彙總下鑽至 Session；歷史詳情提供 Session 用量及來源核對入口。切換時保留搜尋與篩選狀態。共享額度標示「帳號共享」，短期額度不標成對話 Session。

缺資料、不支援、離線、過期及無法定價需有明確狀態；部分小計附涵蓋範圍，未知不用零值代替。圖表之外保留可讀表格及鍵盤操作。估算與實際帳務金額分開呈現，不把月費自動分攤到專案。

來源連線與選用本機 metrics 收集在設定中啟用；用量檢視不執行 Agent 或注入 CLI 命令。詳細行為見[用量規格](usage-spec.md)，整組介面在 P1 交付。

## 客製化與可及性

主題設定共用 design tokens，再分別映射至介面與 xterm 色票。提供字型、大小、對比與快捷鍵設定，支援鍵盤操作、清楚的焦點順序與螢幕閱讀器驗證。

UI 框架採宣告式狀態。Terminal 高頻輸出由 xterm 實例接收，不把每段輸出轉成整個畫面的重新渲染。

## 介面驗收任務

使用者不經說明即可辨認目前專案、工具、焦點與程序狀態；能以鍵盤完成搜尋、預覽、接續與分割。至少兩個 Terminal 在同一畫面持續輸出，調整布局不重啟程序。

導覽變更另驗證：全新掃描有歷史但專案清單為空、預覽加入、加入既有目錄、建立新資料夾、重複提交及取消、重開保存、移出後仍可搜尋及操作已開啟工作區。使用隔離雲端合成路徑的結果不能代替使用者電腦上的原生目錄操作驗收。
