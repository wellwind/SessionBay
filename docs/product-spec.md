# Session Bay 產品功能規格

本規格定義建議 MVP 的可觀察行為與驗收條件。P0 是第一版完整工作恢復流程的必要範圍；P1、P2 為後續候選，尚未實作。

## 名詞與實體

| 名詞 | 定義 |
| --- | --- |
| Project | 使用者工作的專案單位，MVP 預設以工作目錄識別 |
| Agent installation | 一個工具的可執行檔、版本與資料來源設定 |
| Session | Agent 保存的歷史對話，不代表仍有程序執行 |
| Runtime | 應用管理的 PTY 與子程序，具有啟動、執行、退出等狀態 |
| Workspace tab | 專案內的一個工作區分頁，可以包含多個面板 |
| Pane | 顯示 Agent Terminal 或普通 Terminal 的單位 |
| Transcript | Session 的對話紀錄；與 Terminal 當前畫面緩衝不同 |

## F01 工具偵測與資料來源設定

首批建議支援 Codex CLI、Claude Code CLI。透過已知 adapter 偵測工具與歷史位置；提供手動指定執行檔與資料目錄。各工具分開顯示「可啟動」、「有可讀歷史」、「資料來源錯誤」狀態。

驗收條件：

- 工具已移除但歷史仍在時，可以搜尋與預覽；恢復動作提示指定執行檔。
- 工具有安裝但沒有歷史時，可開始新工作，不顯示掃描失敗。
- 自訂資料位置與多個來源可被識別，不能直接合併不同來源的同名 Session ID。
- 不聲稱能自動識別所有 AI 工具；未支援工具顯示能力邊界。

## F02 專案總覽與目錄分組

預設依紀錄中的工作目錄分組，顯示名稱、完整路徑、最近活動、Agent 類型與 Session 數。支援專案搜尋、最近活動排序、釘選與手動加入沒有歷史的目錄。

驗收條件：

- 相同目錄中的不同 Agent 出現在同一專案。
- 名稱相同、路徑不同的專案可以清楚區分。
- 失效目錄仍可查看歷史；恢復前可選擇重新定位目錄。
- 重新定位保留原始紀錄路徑與 cwd，不修改來源 transcript。
- cwd 缺失的紀錄進入「未分類」，不猜測成目前工作目錄。
- symbolic link、大小寫與 worktree 的合併採明確規則，詳見整合規格。

## F03 跨 Agent Session 清單

依最後活動時間排序，顯示 Agent、標題或替代標籤、時間、工作目錄與封存標記；分頁載入。支援依專案、Agent、日期與封存狀態篩選。

驗收條件：

- 缺標題時使用首則可讀使用者訊息片段，仍缺失則使用短 ID。
- 清楚標示可搜尋的資料範圍、索引中與解析不完整狀態。
- 子代理與分支保留來源關係；預設不把每個子代理列成獨立主工作。
- 檔案修改時間只能作為活動時間的 fallback，不能假裝是對話事件時間。

## F04 搜尋與對話預覽

MVP 提供標題、使用者訊息與 agent 回覆的關鍵字搜尋。工具輸出內容的全文索引列為後續可選項，避免大量建置日誌淹沒結果。搜尋結果提供命中片段、Agent、專案與時間。

預覽優先顯示最近對話、最後的使用者要求及 agent 回覆；可以展開更早內容。完整內容按需讀取，與 Terminal 畫面分開呈現。

驗收條件：

- 可跨 Codex、Claude Code 搜尋，也能限縮到目前專案。
- 中文、英文與程式碼識別字具有可說明的匹配規則；中文搜尋是 MVP 驗證項目。
- 若結果來自尚未更新的索引，能顯示來源已變更並重新載入。
- 長對話分段讀取，附件、壓縮與不支援事件有占位說明。
- 搜尋或預覽不會啟動 Agent，也不會把內容送到模型服務。

## F05 恢復 Session 與開始新工作

恢復前檢查工具、來源紀錄與目錄。使用原 CLI 的恢復能力在 PTY 中執行；透過參數陣列與獨立 cwd 傳入，不組合任意 Shell 指令字串。

驗收條件：

- 點選恢復後，在對應專案開啟或聚焦 Agent 面板。
- 同一 Session 已由本應用開啟時，預設聚焦既有面板；另開副本需明確操作與工具支援。
- 對應程序已在外部執行但無法確認附接能力時，提示狀態未知，不任意中止外部程序。
- CLI 恢復失敗時保留錯誤訊息，允許重新指定工具、工作目錄或改開新 Session。
- 成功啟動程序不代表已成功載入歷史；未取得可靠訊號時，顯示「已啟動，待確認 Session」。
- 新工作沿用專案目錄；可選 Agent 或普通 Shell。
- 沿用 Agent 本身的登入與權限流程，不預設使用跳過權限的旗標。

## F06 普通 Terminal

提供預設 Shell、Profiles、鍵盤輸入、中文輸入法、複製貼上、捲動、搜尋、調整大小與程序退出顯示。可從專案直接開啟，也可選其他目錄。

相容性至少驗證目標平台上的 Shell、Codex、Claude Code、互動式提示、Vim；macOS 或 Linux 另驗證 tmux。進階圖片與鍵盤協定按需求追加。

普通 Terminal 裡手動執行 Agent 時，仍維持普通面板。除非取得可靠 Session ID 或使用者明確建立關聯，不自動轉成已關聯的 Agent 面板。

## F07 工作區分頁與分割面板

結構為 Project → Workspace tab → Pane。單一分頁可只有一個面板，也可以左右或上下分割，混用 Agent 與普通 Terminal。

驗收條件：

- 至少兩個 Terminal 可同時可見並持續執行，各有獨立 PTY。
- 可以拖曳調整比例、切換焦點、暫時最大化與還原面板。
- 改變尺寸後依實際字元尺寸更新 PTY 行列數。
- 切換分頁不會重啟或結束背景程序；輸出維持順序且緩衝有上限。
- 不提供預設廣播輸入，以免命令被送到其他專案。
- MVP 的關閉面板會結束其受管程序並移除視圖；執行中顯示一次明確確認。退出程序後可保留最後畫面供檢視。
- 隱藏側欄、切換分頁、暫時最大化均屬視圖操作，不等於關閉程序。

## F08 基本客製化與布局保存

MVP 支援亮暗主題、終端色票、字型與大小、快捷鍵、Shell Profiles、預設 Agent，以及工作區布局保存。設定須有版本與驗證，快捷鍵衝突可見。

重開應用可還原專案與布局占位；不自動重新執行先前任意 Shell 指令。Agent 面板提供接續入口，普通 Terminal 提供重新開啟 Shell。程序跨應用退出存活另見 F13。

## F09 增量索引與錯誤處理

先讀本機索引，再背景同步來源；提供掃描進度、取消、重新掃描與清除索引。清除索引不刪除原始歷史。

驗收條件：

- 容忍 JSONL 尚未寫完的尾行與無法解析的單筆事件。
- 支援檔案追加、截斷、替換、刪除與封存移動。
- 單一來源錯誤不阻擋其他來源與 Terminal 操作。
- 資料來源被刪除時，相關搜尋內容不永久殘留；偵測後清理衍生索引。
- 不修改原 Agent 的 transcript、SQLite 或設定檔。

## 後續功能

P1 包含手動工作狀態、Session 別名、接續筆記、Repo 分組、摘要與可預覽的跨 Agent 交接。手動狀態與程序狀態分開；Agent 停止輸出不表示任務完成。

P2 包含獨立 Session daemon、重新附接、自動派工、同步與外掛。外掛能力、遠端 SSH 管理、Shell integration、圖片協定等，需另訂規格與優先序。

## 整體驗收

使用者能在同一專案找到不同 Agent 的歷史，預覽並恢復正確 Session，再分割出普通 Terminal 執行測試；索引同步與大量輸出時，仍可輸入、切換面板與搜尋。效能的量測方法與暫定門檻見[開發路線圖](roadmap.md)。
