## One project, many agents

Claude Code writes the code, Codex generates the assets, and when your quota runs out you switch to OpenCode with a free model. The context of one project ends up scattered across several agents, each with its own history in its own folder. Session Bay brings it together by project, so you can search, preview and resume any session in the right folder with one click.

<CardGrid>
  <Card title="One history for every agent" icon="magnifier">
    Claude Code, Codex CLI, OpenCode, Grok Build and Antigravity CLI. Full-text search, including CJK, plus filters and a read-only preview.
  </Card>
  <Card title="Real terminals" icon="seti:shell">
    Tabs and split panes backed by real PTYs. Agents keep running when you close the window and reattach when you come back.
  </Card>
  <Card title="Knows when an agent needs you" icon="warning">
    Status badges and system notifications when an agent waits for input, finishes or fails. Click a notification to jump to its pane.
  </Card>
  <Card title="Git workbench" icon="github">
    Partial staging, history graph, blame, branches, worktrees, three-way conflicts, and GitHub or GitLab pull requests.
  </Card>
  <Card title="Local and private" icon="approve-check">
    No account, no server, no telemetry. Agent history is read-only unless you explicitly move a session to the system trash.
  </Card>
  <Card title="Free and open source" icon="open-book">
    MIT licensed. English and Traditional Chinese interface.
  </Card>
</CardGrid>
